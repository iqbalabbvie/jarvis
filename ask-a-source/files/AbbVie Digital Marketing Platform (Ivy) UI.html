A full rendering of every component user interface (UI). HTML, CSS, JS code blocks of every component that exist within admpivy.

  • ActionsString together actions that can execute on load or by click.
  • Activity TrackerDisplay progress of multiple activities.
  • Back To TopAllows the user to easily get back to top.

  • Brand Explorer (Classic)* Deprecated
  • BreadcrumbLists a trail of pages underneath the header.

  • Charts (Pie)Pie chart data visualization with purpose.

    * Restricted
  • Flexbox ContainerFlexible container that resize items to fill available free space. Place any component within.

  • Flexbox-v2 ContainerFlexible container that resizes items to fill available free space. Place any component within. Use standard flexbox CSS

  • GridRenders a set of pages in a grid format based on page property values of the individual pages.
  • Product GridProduct list renders a list of data from a json/api into a grid format.
  • HeaderAnchored to the top of the page as a base component.
    * Deprecated
  • Header V2Anchored to the top of the page as a base component. Accessibility enhanced.
